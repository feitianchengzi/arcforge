# ArcForge On Demand

执行显式调用，将调用者指定的技能名称或任务意图解析为一个已校验的 catalog 技能，再读取其指令。

## 约束

- 调用来源必须是用户显式请求或宿主程序的显式调用配置。安装了本入口、工具可用、场景允许按需技能，都不构成调用指令。
- Agent 的语义判断用于显式调用后的候选选择，不用于自行决定触发入口；普通任务不枚举或预加载 catalog。
- 本入口是通用 ArcForge 能力，不依赖特定 Runtime、产品、动态工具名称或线程机制。
- 一次加载一个技能。目标技能不扩大用户授权，也不授权继续发现其他隐藏技能。
- 遵守调用方提供的 catalog 范围；禁用、未找到或校验失败时，不改用全局目录或其他入口绕过限制。

## 1. 读取调用输入

输入为本次显式调用携带的技能名称或任务意图，以及调用方提供的查询入口和范围。

用户无需预先知道技能名称；只有调用未提供名称或用途、且上下文无法确定时才询问。不得把普通业务任务解释成本入口的调用。

宿主提供查询工具或命令时，按宿主声明的协议使用；特定工具名称、参数和回退方式由宿主说明。没有宿主接口或范围声明时，使用标准 ArcForge CLI。宿主声明的接口不可用时报告错误，不自行扩大查询范围。

退出条件：确认显式调用的目的、查询入口和范围。

## 2. 选择候选

明确技能名称时执行 exact resolve；任务意图路径先执行 list。标准 CLI 命令为：

```text
arcforge catalog list
arcforge catalog resolve --query <qualifiedName>
```

仅根据候选的名称、摘要、版本和状态判断其领域、流程、输入输出是否覆盖调用目的。完整任务描述用于语义判断，不作为名称 query，也不使用关键词计分或目录顺序代替判断。

候选唯一合适时用其 `qualifiedName` exact resolve。没有合适候选时说明缺口；多个候选无法可信区分时展示最小必要信息并询问。

退出条件：获得唯一 `resolved` 结果。`not-found`、`ambiguous`、版本冲突、内容漂移或路径校验失败时均不加载；如需治理，报告原因并交还 ArcForge 的管理流程。

## 3. 加载并执行

完整读取 `<resolved.installedPath>/SKILL.md`，按其中的 reference 路由读取必要文件。使用解析返回的实际路径，不用同名副本替代，也不递归读取其他候选的正文。

按目标技能完成本次调用的任务。另一技能的加载需要另一次用户显式调用或宿主显式配置的调用，不因 Agent 判断缺少能力自动继续查询。

## 最终汇报

简要说明实际加载的 `qualifiedName`、路径和用途；未能加载时说明状态与原因。查询和加载不执行安装、同步、删除、发布或权限提升。
